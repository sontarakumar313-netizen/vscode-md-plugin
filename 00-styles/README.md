# Markdown Interactor 基本样式文件

本目录保存可以复制到工作区的基础样式设置。复杂的布局、交互和功能块结构由插件内置 CSS 负责；这些文件只提供字体、字号、行高、间距、颜色和圆角等基本值。

## 使用方式

1. 在命令面板运行 `Markdown Interactor: Generate Default Workspace CSS`，或将任意主题文件复制为项目根目录下的 `.vscode/markdown-interactor.css`。
2. 修改后，在编辑器顶部工具栏的“更多”菜单中点击“刷新加载工作区 CSS”。
3. 如果删除工作区 CSS，插件会回到内置的浅色/深色默认主题。

工作区 CSS 只读取当前 Markdown 文件所属的工作区，不会向父目录查找。每个编辑器面板初始化时加载一次，修改文件后需要手动刷新。

## 基本设置框架

所有基础样式文件使用同一组段落：

1. **编辑器表面与语义颜色**：背景、文字、弱化文字、边框、强调色、选区。
2. **字体**：正文/源码字体、字号、行高、字距。
3. **编辑器与块间距**：正文内缩、段落间距、引用间距、折叠区边界内缩。
4. **标题与正文**：H1–H6 的字号、字重和标题边框。
5. **引用、提示和列表**：引用背景、GitHub Alert 类型色、列表标记色。
6. **代码、公式和图表**：行内/块级代码、工具栏、公式背景、图表背景。
7. **表格和媒体**：表格斑马纹、单元格内距、图片/组件圆角。
8. **工具栏、面板和控件**：面板、工具栏、滚动条和控件圆角。

修改时优先调整 `.vditor { ... }` 中的变量，不要复制插件内部的布局选择器。这样可以让 WYSIWYG、分屏预览、源码编辑、数学公式、Mermaid、代码块、表格、媒体、YAML front matter、HTML 和折叠区共享同一套基础设置。

## 文件

- `light-paper-day.css`：暖白纸张、蓝绿色强调的浅色基础设置。
- `dark-graphite-ember.css`：低饱和暖黑、琥珀强调的深色基础设置。
- `dark-midnight-neon.css`：深海蓝黑、青色和蓝紫强调的深色基础设置。

这些文件是可选的工作区主题；内置浅色/深色主题仍由插件根据 VS Code 主题和设置自动选择。
